# Muslim Engineering Student Society Website Context

## Project

This project is a one-page website for the Muslim Engineering Student Society at the University of Houston.

Organization name: Muslim Engineering Student Society  
Acronym: MESS  
School: University of Houston

## Purpose

The website should feel like a real, professional university student organization site for Muslim engineering students. It should be suitable for organization submissions, faculty review, student recruiting, and sponsor conversations.

## Technical Stack

- Next.js
- TypeScript
- Tailwind CSS
- No database
- No login
- No dashboard
- No payment system
- No complex backend
- Avoid unnecessary dependencies

## Design Direction

The visual direction should blend:

- Engineering aesthetic: subtle grid patterns, technical structure, clean cards, clear systems, and modern layout.
- Muslim identity: subtle Islamic geometric accents, warm tone, community-centered copy, and faith-aware positioning.
- University of Houston branding: UH red as the primary accent, white/light backgrounds, dark gray or black text, and optional small gold accents.

## Required Sections

- Navbar
- Hero
- Who We Are
- What We Offer
- Executive Board
- Statistics
- Join / Sign Up
- Contact and Socials
- Footer
