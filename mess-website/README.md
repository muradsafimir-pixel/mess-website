# Muslim Engineering Student Society Website

Clean one-page website skeleton for the Muslim Engineering Student Society at the University of Houston.

## Local Development

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open `http://localhost:3000`.

## Edit Placeholder Content

Most editable organization content is near the top of `app/page.tsx`:

- Officer names
- Officer roles
- Sign-up link
- Email
- Instagram
- LinkedIn
- GroupMe/Discord link

## Deploy to Vercel

1. Push this project to GitHub.
2. Go to `https://vercel.com/new`.
3. Import the GitHub repository.
4. Keep the detected framework as Next.js.
5. Click Deploy.
